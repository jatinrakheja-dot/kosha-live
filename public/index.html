About this briefing

This one is written by the rules engine, sentence by sentence, from the same numbers you see on each position. Nothing in it is a prediction.

On Pro, the monthly briefing is narrated by an AI model from the engine's output, reads like a note from a chief of staff, and is labelled as AI-generated permanently. The model never computes a mark — it only explains one the engine already produced.
